Test program for passing structs to and from functions using the pascal and register ABIs.

This was developed on a Debian box, exact commands / program name may differ.

1) Build the pascal library using `pascal/build.sh`
2) Make the test program using `make`
3) Run the test program `./pascaltest`. Note that every test has its own character, you can run a specific test using `./pascaltest <character>`. `./pascaltest a` will run just the first test.
